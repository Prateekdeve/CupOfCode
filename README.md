## 📌 About The Repository

**CupOfCode** is a dedicated repository built for consistent, step-by-step learning of Data Structures and Algorithms (DSA). From fundamental programming concepts to complex problem-solving patterns, this collection serves as a daily habit tracker and reference guide for computer science fundamentals.

---

## 🗺️ Learning Roadmap

Follow the topics in this structured order for a smooth and progressive learning experience:

| # | Topic | Focus Areas | Status |
|---|---|---|:---:|
| 01 | **Basics** | Syntax, Data Types, Conditionals, Loops, I/O | 🟢 Active |
| 02 | **Pattern Printing** | Nested Loops, Space Logic, Grid Geometry | 🟢 Active |
| 03 | **Basic Math** | Digit Extraction, GCD/LCM, Primality, Divisors | 🟢 Active |
| 04 | **Recursion** | Base Cases, Call Stack, Backtracking, Subsets | 🟢 Active |
| 05 | **Sorting** | Bubble, Selection, Insertion, Merge, Quick Sort | 🟢 Active |
| 06 | **Hashing** | Frequency Maps, Hash Tables, Collisions, Sets | 🟢 Active |
| 07 | **Arrays** | Two Pointers, Sliding Window, Subarrays, Prefix Sum | 🟢 Active |
| 08 | **Strings** *(Upcoming)* | Manipulation, Anagrams, Two-Pointer Strings | 🟡 Planned |
| 09 | **Linked List** *(Upcoming)* | Singly, Doubly, Cycle Detection, Reversal | 🟡 Planned |
